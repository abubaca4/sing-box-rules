# sing-box-rules

*[🇬🇧 Read in English](README.md)*

Репозиторий создан для автогенерации списков (rule-sets) sing-box, которых я не нашёл в сети, но посчитал полезными для себя. Списки автоматически собираются и обновляются каждый день с помощью GitHub Actions.

В данный момент он содержит 2 списка. Я буду добавлять списки и их описание по мере появления необходимости, вы также можете предложить свои идеи.

## Как использовать

Вы можете подключить списки через следующие ссылки:

**Через jsDelivr (CDN):**
`https://cdn.jsdelivr.net/gh/abubaca4/sing-box-rules@rule-sets/<имя списка>.srs`

**Через GitHub Raw:**
`https://github.com/abubaca4/sing-box-rules/raw/refs/heads/rule-sets/<имя списка>.srs`

## Списки

### `global-tlds`
Списки доменов 1 уровня, существующих в интернете.
*   **Источник:** [Официальный список IANA](https://data.iana.org/TLD/tlds-alpha-by-domain.txt)
*   **Применение:** Идея его использования в том, чтобы направить все DNS запросы к доменам, которые не относятся к глобальному интернету, сразу на локальный DNS.
*   **Пример применения:**
    ```json
    {
      "rule_set": "global-tlds",
      "invert": true,
      "server": "dns-local"
    }
    ```

### `router-domains`
Список доменов, которые используют вендоры роутеров для открытия интерфейса роутера. 
*   **Примечание:** Сюда следует добавлять только те домены, которые располагаются на глобально доступных доменах первого уровня.
